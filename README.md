# زمركان إنجلش · عرض المفردات التفاعلي

عرض تقديمي تفاعلي بالعربي للدروس الخمسة من قناة **zAmericanEnglish**:
الحيوانات · المنزل والأثاث · الخضروات · المهن والملابس · الصفات المتضادة

## المميزات
- **100 كلمة** — لكل كلمة صورة مأخوذة من شرح الأصلي (بدون ظهور المتحدث)
- ترجمة **عربية** للكلمة ولجملة المثال
- زر **🔊 نطق** للكلمة بالإنجليزي، وللجملة بالإنجليزي، وللترجمة العربية
- خريطة دروس قابلة للنقر + تنقّل بالأسهم

## التشغيل
افتح `index.html` مباشرة في أي متصفح — لا يحتاج إنترنت ولا تثبيت.
